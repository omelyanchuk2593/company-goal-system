# Система целей компании

Скилл для **Claude Code и Codex**, который помогает построить рабочий процесс
целеполагания: выбрать общий ориентир, сформулировать личные результаты,
согласовать их и проверить выполнение по доказательствам.

Методическая основа — подход пяти корзин, разобранный Константином Карпушиным.
Это самостоятельная адаптация для AI-ассистента. Она сохраняет ограничения
метода и отдельно обозначает добавленные шаблоны, алгоритмы и варианты внедрения.

## Что получится

- Паспорт компании: общая цель, измерение, ограничения и выбранные правила.
- Конструктор направлений, в которых сотрудники предлагают свои цели.
- Личные портфели: **две S, две M, одна L**, максимум пять занятых мест.
- Короткие карточки целей с критериями, доказательствами и ответственными.
- Правила оценки PM, независимого ревью и разрешения споров.
- План пилота и журнал проверки результатов.

Можно начать с одной формулировки или проверить существующий список. Скилл
адаптирует объём работы к запросу и даёт первый полезный результат до длинного
сбора данных. Когда фактов не хватает, он оставляет честный черновик.

## Быстрый старт для участников

**Самый простой способ:** откройте эту страницу в Claude Code или Codex и напишите:

> Установи скилл company-goal-system из этого репозитория для моего ассистента.
> Затем помоги настроить систему целей моей компании. Начни с трёх важных вопросов
> и проекта первой цели. Моя компания: [что делаем, размер команды, проблема].

Ассистент может прочитать README и выполнить установку в своём разрешённом
окружении. Для ручной установки нужны Git и Python 3.10+:

```bash
git clone https://github.com/omelyanchuk2593/company-goal-system.git
cd company-goal-system
python tools/install.py --target both
```

В Windows используйте `py -3` вместо `python`, если так настроен Python.
Установщик копирует только файлы скилла. Он не меняет модели, API-ключи,
настройки оплаты или существующие отличающиеся версии скилла.

| Где использовать | Команда |
|---|---|
| Только Claude Code | `python tools/install.py --target claude` |
| Только Codex | `python tools/install.py --target codex` |
| Оба | `python tools/install.py --target both` |
| Посмотреть пути без установки | `python tools/install.py --target both --dry-run` |
| Только в выбранном проекте | `python tools/install.py --target both --scope project --project /path/to/project` |

Персональные пути: `~/.claude/skills/company-goal-system` и
`~/.agents/skills/company-goal-system`. Откройте новую сессию ассистента после
установки. В Claude Code вызовите `/company-goal-system`, в Codex —
`$company-goal-system` или явно попросите использовать скилл.

Без Python скачайте архив из [Releases](https://github.com/omelyanchuk2593/company-goal-system/releases/latest) и скопируйте **папку
`company-goal-system` целиком**, вместе с references/assets/scripts, в нужную
папку skills. Python нужен только для автоматического аудита CSV; основной
диалог работает без него. Это инструкция для локальных Claude Code/Codex;
облачные продукты могут иметь отдельный механизм загрузки навыков.

Пути и формат проверены по официальной документации:
[Codex / Build skills](https://learn.chatgpt.com/docs/build-skills),
[Claude Code / Skills](https://code.claude.com/docs/en/skills).

## Как пользоваться

**Внедрить систему**

> Используй company-goal-system. У нас сервисная компания, 38 сотрудников.
> Руководители выдали каждому по 12 KPI со сроком 31 декабря. Помоги перейти
> к осмысленным целям и подготовь план пилота. Не придумывай наши показатели.

**Отредактировать одну цель**

> Проверь цель «вести CRM и обучать менеджеров». Я руководитель продаж.
> Покажи, что здесь обязанность, какие результаты можно выбрать и каких данных
> не хватает. В корзинах уже две S-цели и одна M.

**Проверить результат**

> По согласованной цели к сроку нужно было получить 75 принятых результатов.
> Есть 74. Помоги провести честное ревью и обсудить следующую попытку.

**Продолжить работу**

> Прочитай наш паспорт, реестр и журнал решений. Продолжи с нерешённых вопросов,
> сохрани ID и историю целей. Не меняй критерии задним числом.

## Что важно в подходе

| Принцип | Как скилл его применяет |
|---|---|
| Меньше и яснее | Формулировка результата короче 250 символов |
| Ограниченная ёмкость | 2 S до 2 месяцев, 2 M до 6, 1 L до 12; непрерывное обновление |
| Личный выбор | Стратегическая рамка компании, предложения сотрудника |
| Качество цели | Сначала SMART, затем амбициозность; 1–2★ возвращаются на доработку |
| Честный результат | Исходный критерий + evidence; 74/75 не округляется до достижения |
| Поддержка | Честный провал разбирается без автоматических штрафов |

Границы месяцев в реализации непересекающиеся: S≤2, 2<M≤6, 6<L≤12.
Правила, которые источник описывает не полностью, видны в
[карте методики](skills/company-goal-system/references/source-map.md).

## Проверка реестра

Скопируйте [CSV-шаблон](skills/company-goal-system/assets/goal-register.csv),
заполните его со скиллом и проверьте:

```bash
python skills/company-goal-system/scripts/audit_goals.py path/to/goals.csv --json
```

Проверяются структура, длина формулировок, календарные сроки и переполнение
корзин. Статусы ожидания проверки и спора продолжают занимать место.
Скрипт не оценивает людей и не подтверждает подлинность документов.

## Для авторов изменений

```bash
python -m unittest discover -s tests -v
python tools/check_release.py
python tools/package_skill.py
```

Архивы создаются в `dist/`. В каждый входит одна устанавливаемая папка скилла.
Исходные материалы занятия, частные данные и результаты реальной компании
не должны попадать в Git. Локальные рабочие результаты в `goal-system/`
исключены из отслеживания.

Границы проверки и результаты сценариев описаны в [evals/README.md](evals/README.md).
Этот пакет не требует MCP, API-ключей или сторонних библиотек Python.
Работу модели обеспечивает выбранный пользователем ассистент на его обычных условиях.
