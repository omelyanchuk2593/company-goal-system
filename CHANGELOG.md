# Изменения

## 1.0.0 — 2026-10-30

- Первая самостоятельная реализация методики пяти корзин для Claude Code и Codex.
- Три маршрута: запуск системы, аудит целей и проверка выполнения.
- Карта источников с разделением подтверждённых правил, неоднозначностей и адаптаций.
- Пять рабочих шаблонов и вымышленный пример внедрения.
- Аудит CSV, установка без перезаписи отличающейся версии и воспроизводимая упаковка.
- Автоматические тесты и четыре поведенческих сценария с сохранёнными ответами.
